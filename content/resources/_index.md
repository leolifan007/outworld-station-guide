## 这游戏有哪些资源？怎么用？

我第一次玩的时候，看到一堆矿物名字完全不知道哪个值钱哪个没用。硅矿有什么用？跟铁矿混线会不会出事？这篇给你全部理清楚。

资源分四个层级，越往后越稀越低产量：

| 层级 | 类型 | 代表资源 |
|------|------|----------|
| T1 | 基础矿物 | 铁矿、铜矿、硅矿 |
| T2 | 加工金属 | 铁锭、铜锭、钢合金 |
| T3 | 高科技材料 | 电路板、合金板、燃料棒 |
| T4 | 稀有物质 | 外星遗物、反物质、氦-3 |

---

## T1：基础矿物（满地都是）

### 铁矿（Iron Ore）
- **采集：** 采矿钻机 → 随便找个小行星
- **用途：** 一切的基础——建筑材料、铁板、初级零件
- **常见程度：** ★★★★★ 满大街
- **建议：** 开局就在最近的小行星上装钻机，别跑远

### 铜矿（Copper Ore）
- **采集：** 采矿钻机 → 小行星
- **用途：** 电路板、电力设施
- **常见程度：** ★★★★☆ 也很多
- **建议：** 初期先挖铁再挖铜，铜的用量比铁少一半

### 硅矿（Silicon Ore）
- **采集：** 采矿钻机 → 特殊小行星（带闪烁标记的）
- **用途：** 微芯片、科技组件
- **常见程度：** ★★★☆☆ 需要找一找
- **踩过的坑：** 硅矿和铁矿混线容易卡住。建议单独建一条硅矿产线。

---

## T2：加工资源（进熔炉/装配机）

### 基础加工链

```
铁矿 → [熔炉] → 铁锭（Iron Ingot）
铜矿 → [熔炉] → 铜锭（Copper Ingot）
硅矿 → [熔炉] → 硅晶（Silicon Crystal）

铁锭 + 铜锭 → [高级冶炼厂] → 钢合金（Steel Alloy）
铁锭 + 硅晶 → [装配机] → 电路板（Circuit Board）
```

<div class="callout callout-tip">
  <h4>初期产线设计建议</h4>
  <p>铁矿和铜矿可以共用一组仓库，用 Buffer 模式平衡。硅矿最好单独一条线——用量少但纯度高要求高，混线容易被铁矿挤占产能。</p>
</div>

## T3：高科技材料（开始烧脑了）

### 电路板（Circuit Board）
- **配方：** 铁锭 x2 + 硅晶 x1
- **用途：** 几乎所有高级建筑都需要
- **建议产量：** 10-15 单位/秒
- **经验：** 电路板是中期最大的瓶颈。很多建筑都吃掉大量电路板，务必保证产线优先。

### 合金板（Alloy Plate）
- **配方：** 钢合金 x3 + 铜锭 x1
- **用途：** 装甲、星舰建造
- **建议产量：** 5-8 单位/秒
- **经验：** 前期不需要合金板，但到了造星舰阶段用量暴涨。提前铺线不会亏。

### 燃料棒（Fuel Rod）
- **配方：** 铀矿 x2（需要化工厂）
- **用途：** 小型反应堆燃料
- **注意：** 铀矿只在有辐射图标的小行星出现。带防护设备或者直接远程自动化采集（别自己飞过去搬）。

---

## T4：稀有物质（终局追求）

### 外星遗物（Alien Relic）
- **获取：** 探索新星球 / 击败虫洞入侵者
- **用途：** 解锁强力升级、武装无人机
- **稀有度：** 获取不稳定但也不至于绝版
- **建议：** 见到了就囤，不要花在非必要升级上

### 反物质（Antimatter）
- **解锁：** 科技 Antimatter Tech（后期）
- **生产：** 大型粒子对撞机（需要先建好）
- **用途：** 方舟飞船核心组件
- **稀有度：** 终局资源，不着急

### 氦-3（Helium-3）
- **采集：** 气体收集器 → 气体巨行星
- **用途：** 聚变反应堆燃料
- **稀有度：** 需要特定星球
- **建议：** 建聚变堆之前先派侦察船找到气体巨行星

## 星球资源分布速查

| 星球类型 | 主要资源 | 该怎么建站 |
|----------|----------|------------|
| 岩质行星 | 铁矿、铜矿 | 建采矿前哨，矿送回主星加工 |
| 硅质行星 | 硅矿、稀有合金 | 重点开发，硅很重要 |
| 气体巨行星 | 氦-3 | 放气体收集器就行 |
| 辐射带 | 铀矿 | 小心辐射，自动化采集 |
| 遗物星 | 外星遗物 | 需要带战斗能力去 |

<div class="pro-tip">
  <p><strong>资源管理的核心原则：</strong> 每一级产线宽度至少是下一级的 1.5 倍。如果 T1 矿采 20/秒，T2 熔炉就要能处理约 13/秒，T3 零件保持 8-10/秒。加工有损耗，上游必须有冗余。</p>
</div>
