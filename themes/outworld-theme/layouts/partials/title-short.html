{{- /* /layouts/partials/title-short.html Zero-maintenance sidebar label extractor. Usage: {{ partial "title-short" .Title }} // string title -> short label (1-2 words) {{ partial "title-short" (dict "title" .Title) }} // same as above {{ partial "title-short" (dict "title" .Title "variant" "long") }} // longer label (1-3 words) The "long" variant is used by sidebar-l2.html ONLY when a short label collides with another article in the same category, so the colliding pair becomes distinguishable. Every non-colliding label keeps the short form. Pipeline (all algorithmic, no dictionary, no manual config): 1. Normalize unicode dashes to ASCII " -- " / " - " 2. Strip all colons / sentence punctuation (subtitle separators) 3. Strip "Outworld Station" prefix (case-insensitive) 4. Split on " -- " then " - " and keep first part 5. Strip trailing " Guide" 6. Pick the first significant words (skip articles, conjunctions, &, +) 7. Cap length (short = 18, long = 26) */ -}} {{- $title := . -}} {{- $variant := "short" -}} {{- if reflect.IsMap . -}} {{- $title = .title -}} {{- $variant = .variant | default "short" -}} {{- end -}} {{- $cap := 20 -}} {{- $maxWords := 2 -}} {{- if eq $variant "long" -}} {{- $cap = 26 -}} {{- $maxWords = 3 -}} {{- end -}} {{- $s := $title -}} {{- /* 1. Normalize unicode dashes to ASCII (signature: replace S OLD NEW) */ -}} {{- $s = replace $s "—" " -- " -}} {{- $s = replace $s "–" " - " -}} {{- /* 2. Strip all colons + sentence punctuation that may stick to words */ -}} {{- $s = replace $s ":" "" -}} {{- $s = replace $s "?" "" -}} {{- $s = replace $s "!" "" -}} {{- /* 3. Strip "Outworld Station" prefix variants */ -}} {{- $s = replaceRE "(?i)^outworld station -" "" $s -}} {{- $s = replaceRE "(?i)^outworld station" "" $s -}} {{- $s = strings.TrimLeft " -" $s -}} {{- /* 4. Split on subtitle separators and keep first part */ -}} {{- $s = index (split $s " -- ") 0 -}} {{- $s = index (split $s " - ") 0 -}} {{- /* 5. Strip trailing " Guide" (case-insensitive) */ -}} {{- $s = replaceRE "(?i) guide" "" $s -}} {{- /* 6. Trim */ -}} {{- $s = strings.TrimRight " .,;:?" $s -}} {{- $s = strings.TrimLeft " " $s -}} {{- /* 7. First significant words */ -}} {{- $words := split (strings.TrimLeft " " $s) " " -}} {{- $picked := slice -}} {{- $stop := dict "and" 1 "or" 1 "&" 1 "+" 1 "the" 1 "a" 1 "an" 1 "of" 1 "for" 1 "to" 1 "in" 1 "on" 1 "at" 1 "with" 1 "by" 1 "from" 1 "as" 1 "into" 1 "your" 1 "you" 1 "i" 1 "how" 1 "what" 1 "why" 1 "when" 1 -}} {{- range $w := $words -}} {{- $lw := lower $w -}} {{- if not (index $stop $lw) -}} {{- $picked = $picked | append $w -}} {{- if eq (len $picked) $maxWords -}}{{- break -}}{{- end -}} {{- end -}} {{- end -}} {{- $result := "" -}} {{- if $picked -}} {{- $result = delimit $picked " " -}} {{- else -}} {{- $result = $s -}} {{- end -}} {{- /* 7b. Cap length — only truncate when genuinely needed (avoids ugly '…' artifacts) */ -}} {{- if gt (len $result) $cap }}{{ substr $result 0 $cap }}{{ else }}{{ $result }}{{ end -}}
