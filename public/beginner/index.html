新手入门指南 — 第一小时生存与起步

Outworld Station 新手入门教程。从空间站搭建、资源采集到第一个自动化流水线，手把手带零基础玩家完成开荒。

目录

    欢迎新手指挥官

    第一次启动 Outworld Station，你面前的可能是一个空荡荡的空间站核心和一堆看不懂的英文界面。别慌，本指南带你在第一小时内完成从零到自动化流水线的全过程。

    新手必读

    Outworld Station 没有官方中文，但游戏的核心操作其实不复杂。跟着本指南走完前 60 分钟，你将具备独立探索游戏的能力。

    第一阶段：起步（0-10 分钟）

    1.1 初始空间站布局

    游戏开始时，你拥有一个基础的空间站核心（Station Core）。这是你一切建筑的起点。

    关键操作：

    1. 按 B 打开建造菜单（Building Menu）
    2. 基础建筑分类在 Infrastructure 选项卡
    3. 你的第一个目标：放置 Solar Panel（太阳能板）和 Battery（电池）

    第一个 Pro Tip： 初始位置附近总有 2-3 个小行星。在你建造任何设施之前，先把空间站拖到小行星旁边——越近越好。这能节省你第一小时的运输时间。

    1.2 能源系统搭建

    没有能源，任何设施都无法运转。Outworld Station 的能源系统分为三个阶段：

    阶段能源类型推荐数量
    Phase 1太阳能板4-6 块
    Phase 2小型反应堆2-3 个
    Phase 3聚变反应堆1-2 个

    初学者不要跳过太阳能！ 很多新手直接憋反应堆，结果能源供应断断续续，生产线频频停摆。

    第二阶段：第一个自动化（10-25 分钟）

    2.1 资源采集站

    在空间站旁边的小行星上，建造 Mining Drill（采矿钻机）：

    1. 打开建造菜单（B）
    2. 选择 Mining > Mining Drill
    3. 放置在小行星表面（附着点会高亮显示）
    4. 连接能源线到空间站电网

    2.2 隐形物流管线的基础配置

    Outworld Station 的物流系统没有传统传送带。你需要配置库存配对（Inventory Pairing）：

    1. 点击采矿钻机 → 选择 Inventory 标签
    2. 设置 Output 目标为空间站的 Storage Container
    3. 系统会自动在两点间建立隐形物流管线

    物流核心概念

    隐形物流管线的本质是需求驱动：生产端监测到消费端库存不足时，自动触发输送。不需要手动控制传送带速度或分流。

    2.3 第一个加工链

    铁矿（Iron Ore）→ 铁锭（Iron Ingot）→ 铁板（Iron Plate）

    1. 建造 Smelter（熔炉）
    2. 输入：铁矿（来自采矿钻机）
    3. 输出：铁锭
    4. 建造 Assembler（装配机）
    5. 输入：铁锭
    6. 输出：铁板

    第三阶段：扩张基础（25-45 分钟）

    3.1 解锁科技树

    点击 T 打开科技树（Tech Tree）。优先研究顺序：

    优先级科技效果
    SLogistics I解锁物流管线升级，效率+50%
    APower Storage II电池容量翻倍，防止断电
    AMining Efficiency采矿速度+30%
    BAdvanced Smelting解锁合金冶炼

    3.2 空间站扩展

    当你积累了 50+ 铁板和 20+ 电路板后，是时候扩展空间站了：

    1. 建造 Expansion Hub（扩张枢纽）
    2. 选择扩展方向：建议先向小行星方向扩展
    3. 新的模块可以附加新的功能：科研实验室、更多的仓库、防御炮台

    3.3 建设小型舰队

    完成基础自动化后，建造你的第一艘飞船：

    1. 科技树解锁 Shipyard I
    2. 建造 Shipyard 建筑
    3. 建造一艘 Scout Ship（侦察船）
    4. 派它去探索最近的星球——你会找到新的资源和虫洞入口

    第四阶段：常见陷阱（45-60 分钟）

    新手的三个致命错误

    1. 过度扩张： 在自动化还没铺开之前就盲目建新空间站。先保证第一个站能够自给自足。
    2. 忽视防御： 虫洞第一次入侵通常在第 30 分钟左右出现。提前建 2-3 个炮台（Turret）
    3. 库存过小： 初始存储空间只有 100 单位。尽早升级到 Storage II（200 单位），否则生产线会被满库存卡死。

    第六十分钟检查清单

    • 4-6 块太阳能板供电正常
    • 至少 1 个采矿钻机在运行
    • 铁锭 → 铁板 自动化链建立
    • 2-3 个炮台就位
    • 第一艘侦察船出发探索
    • Logistics I 科技解锁
