新手入门指南 — 第一小时生存与起步

Outworld Station 新手教程：英文看不懂？空间站不知道先建什么？从第一分钟开始手把手带你入门，60分钟内完成自动化产线。

第一小时做了什么？照着来就行

我第一次玩的时候，对着空荡荡的空间站和全英文 UI 愣了三分钟。B 键按了不知道建什么，建了太阳能板不知道接电线，搞了半小时连矿都没挖到。

这篇攻略就是我当时最需要的东西。跟我走一遍，前 60 分钟你就能完成产线自循环。

看完这篇你可以

理解所有英文界面的功能、建好第一套能量系统、让采矿钻机动起来、完成铁矿石到铁板的自动化。然后就可以自己瞎折腾了。

第一阶段：起步（0-10 分钟）

空间站初始布局

一进游戏你就在空间站核心（Station Core）里。别慌，先记住这个快捷键：按 B 打开建造菜单。

你第一个要做的三件事：

  1. 别急着建东西。先把你的空间站拖到最近的小行星旁边。怎么拖？鼠标右键按住空间站拖动。越近越好——第一小时的运输时间全看这一步。
  2. 按 B → 选 Infrastructure 选项卡 → 建 2 块 Solar Panel（太阳能板）
  3. 建 1 个 Battery（电池），放在太阳能板旁边

我踩过的坑： 第一次玩的时候我把空间站停在离小行星老远的位置，结果钻机建好后发现连线距离不够。重新拖了两次。所以第一步先把站拉近小行星，别管方向对不对，先贴近再说。

能量系统怎么搭

没电什么都动不了。刚开局你的能量分三个阶段走：

阶段用什么造几个
前30分钟太阳能板4-6 块
30分钟-3小时小型反应堆1-2 个
3小时+聚变反应堆1 个就够了

千万别想着跳过太阳能直接憋反应堆。 我试过，结果就是生产线断断续续，风扇不转钻机不转啥都卡死。太阳能不能一步到位，但它是稳定输出的保障。

第二阶段：第一个自动化（10-25 分钟）

挖矿！挖矿！

在小行星表面建 Mining Drill（采矿钻机）：

  1. 按 B 打开建造菜单
  2. 选 Mining → Mining Drill
  3. 鼠标放到小行星表面，看到有绿色高亮点就是可放置位置
  4. 放下去
  5. 钻机需要通电——确保你建的太阳能板连上了电网

钻机动了之后： 矿会慢慢囤积在钻机的内置存储里。但你不手动去拿就不会自己送回来——需要下一步操作。

关键的隐形物流管线（没有传送带怎么运）

这是 Outworld Station 跟异星工厂最大的区别——不铺传送带，而是做库存配对。

讲人话：你告诉钻机"挖出来的矿送到那边那个仓库"，系统会自动建一条看不见的物流通道。

操作步骤：

  1. 左键点击采矿钻机
  2. 选择弹出的面板中的 Inventory 标签
  3. 在 Output 栏旁边有个 Pair 按钮，点它
  4. 鼠标移动到你的空间站上，选 Storage Container
  5. 好了，系统会自动运矿过来

物流的核心逻辑

这游戏的物流是"需求驱动"的——不是传送带一直转，而是消费端库存不够了，生产端才自动送过去。优点是省空间、不怕堵；缺点是你需要适应这种"看不见的运输"。

第一条加工链

矿挖回来了，接下来把它变成能用的材料：

  1. 建一个 Smelter（熔炉）（在 Production 分类里）
  2. 点击熔炉 → Inventory 标签
  3. Input 点 Pair → 选仓库（选你存矿的那个容器）
  4. Output 点 Pair → 选另一个空的 Storage Container
  5. 熔炉会自动开始工作：矿石 → 铁锭（Iron Ingot）

再建一个 Assembler（装配机），输入链接到铁锭仓库，输出链接到一个新仓库，它会把铁锭加工成 Iron Plate（铁板）。

恭喜！你已经完成了第一个自动化产线：采矿 → 熔炼 → 加工 → 储存。

第三阶段：扩张基础（25-45 分钟）

科技树优先点哪些

按 T 打开科技树（Tech Tree）。优先研究顺序如下：

优先级科技有什么用
SLogistics I物流管线效率+50%，前期最重要的一项
APower Storage II电池容量翻倍，再也不怕阴天
AMining Efficiency采矿速度+30%
BAdvanced Smelting解锁合金冶炼，进入 T2 材料时代

别犯我的错： 我第一次优先点了 Advanced Smelting，结果发现合金配方需要的材料我根本没稳定产线。先搞 Logistics I 和 Mining Efficiency，把基础产线效率拉满再想高端货。

扩展空间站

攒够 50+ 铁板和 20+ 电路板之后，你可以扩建了：

  1. 建 Expansion Hub（扩张枢纽）
  2. 选择朝小行星方向扩展（越靠近矿源越好）
  3. 新模块可以干这些事：加科研实验室、扩仓储、装防御炮台

造第一艘船

自动化产线跑顺了之后，你需要出去看世界：

  1. 在科技树解锁 Shipyard I
  2. 建造 Shipyard 建筑
  3. 造一艘 Scout Ship（侦察船）
  4. 派出去探索最近的星球——你会发现新资源和虫洞入口

第四阶段：三个最容易犯的错（45-60 分钟）

这些坑我全踩过

  1. 太早开辟第二空间站。 第一个站都没实现完全自动化，就急着在别的星球建新站。结果两边都搞不好。先保证一站自给自足。
  2. 完全不建防御。 虫洞第一次入侵大概在第 30 分钟左右。如果没有 2-3 个炮台（Turret），敌人会直接拆你的空间站核心。我第一把就是这么死的。
  3. 存储空间不升级。 初始存储只有 100 容量。很快钻机把仓库塞满，钻机停了，熔炉没矿也停了，整条产线锁死。尽早升级到 Storage II。

新手最容易问的 8 个问题

Q：英文完全看不懂怎么办？

记住这四个词就够了：B = 建造菜单，T = 科技树，Inventory = 库存面板，Pair = 配对。其他你在玩的过程中会慢慢记住。我第一个小时就靠这四个词活的。

Q：太阳能板够用吗？

够起步，但不够长期。30 分钟后你开始有反应堆需求了，直接研究 Reactor Tech I 造小型反应堆。

Q：队友在联机模式里乱建东西怎么办？

权限管理里可以设置谁有权建建筑。游戏里没有明确的权限面板，但主机可以通过 Kick 选项管理队员。组野队建议开场先说好分工，不然很容易出现一个在采矿、另一个已经去造星舰的尴尬场面。

Q：电池（Battery）有什么用？

储能。太阳能板晚上不发电（游戏里有昼夜，虽然周期比地球短），电池存着白天的电供晚上用。前期建 1-2 个就够。

Q：为什么我的熔炉不工作？

① 没通电 ② Input 没 Pair（没矿石来源） ③ Output 没 Pair（产出的锭没地方去）。三条都检查一遍，99% 的问题是这三条之一。我当初每一条都踩过。

Q：B 键打开了但找不到建筑？

建造菜单有分类标签（Infrastructure / Mining / Production / Defense / Tech 等），你找的建筑可能在别的分类里。另外有些建筑需要先解锁科技才会出现。

Q：第一次入侵是什么时候？

大概第 30 分钟，会来第一波小型虫族。不强，但如果你 0 防御就惨了。建议 30 分钟前至少放 2 个炮台。

Q：需要多少存储空间才够？

初期 3-4 个 Storage Container 就够。记住每种材料一个仓库，不要混着放——混着放找东西累死人。

确认以下项目全部搞定，你就可以自由探索了：

  • 4-6 块太阳能板，稳定供电中
  • 至少 1 个采矿钻机在工作
  • 铁矿石 → 铁锭 → 铁板 链条建立
  • 2-3 个炮台就位
  • 第一艘侦察船已经出发
  • Logistics I 科技已解锁
