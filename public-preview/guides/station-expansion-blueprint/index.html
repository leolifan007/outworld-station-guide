Space Station Expansion Blueprint - From Starter Base to Mega-Station

Outworld Station phased expansion plan from starting module to fully-automated mega-station. Blueprints, resource budgets, and upgrade triggers for every phase.

Home › Guides › Mega Station

Your Station Has No Plan. That Is Why It Is a Mess.

You started in the starter module, added rooms as you needed them, connected them with corridors wherever they fit. Now your station is a maze. Assemblers are scattered across three wings. Gas pipes run through the living quarters. Drones take 45 seconds to cross from one end to the other.

A planned station is not just prettier - it is 3x more efficient. Here is the exact expansion blueprint used by Station Level 20+ players.

Quick-Fix: The Golden Expansion Rule

Never add a new module without first planning the next three.

Every room you add determines where the next three rooms go. Place your hub first, then build outward in rings. Production rings, storage rings, defense rings - each with a dedicated purpose.

Result: 60% fewer drone paths, 40% higher assembler uptime, zero dead-end corridors.

The Five Phases of Station Growth

Phase 1: Core Pod (0-2 hours)

Your starting module. Keep it compact. Build only what you need to survive:

  • 1 Cargo Hub (center)
  • 1 Smelter + 1 Assembler
  • 2 Solar Panels + 1 Battery
  • 1 Gas Extractor (oxygen)

Goal: Reach Station Level 3 with a functioning base.

Phase 2: Linear Expansion (2-6 hours)

Add modules in a straight line from the core. This creates a “spine” you can build around later:

  • Production wing (smelters + assemblers)
  • Power wing (solar arrays + small reactor)
  • Storage wing (chests + component storage)

Phase 3: Ring Formation (6-15 hours)

Build a ring around your Phase 2 spine. Each ring has a dedicated function:

  • Inner Ring: High-throughput production
  • Middle Ring: Component manufacturing + storage
  • Outer Ring: Defense + gas extraction

Phase 4: Multi-Level (15-40 hours)

Add upper and lower levels using elevators. Each level mirrors the ring layout below:

  • Level 1: Power generation
  • Level 2: Smelting + refining
  • Level 3: Component manufacturing
  • Level 4: Research + advanced crafting

Phase 5: Mega-Station (40+ hours)

Connect multiple ring clusters via high-speed drone tunnels. Each cluster is a self-contained factory:

Cluster Function Modules Power Required
Alpha Smelting + Refining 20 800 kW
Bravo Component Manufacturing 30 1.2 MW
Charlie Research + Advanced Tech 15 600 kW
Delta Gas Processing + Chemicals 25 900 kW
Echo Defense + Ship Building 18 700 kW

Phase Transition Triggers

Multi-Level to Mega 40+ modules, Fusion unlocked Second cluster foundation

Real Scenario: Complete Rebuild at Station Level 12

My station grew organically for 15 hours. 20 modules scattered in every direction. Drone paths were 50+ seconds. Production was at 55%.

The fix: I saved the blueprint, demolished everything except the core, and rebuilt in a planned ring layout in 3 hours. Same modules, new layout. Production went from 55% to 92%. Drones delivered in 12 seconds instead of 55.

FAQ

Q: Can I relocate a module without rebuilding it?

Yes. Use the Relocate function on any module. It costs 25% of the original build materials. Relocate modules one at a time, starting from the outermost.

Q: How many floors should I plan for?

Start with 2 floors. Add a third when you have 25+ modules. Most mega-stations use 4-5 floors. Each floor should handle one production category.

Q: Should I plan for future tech unlocks?

Leave 3-4 empty module slots in each ring for future expansion. Tech unlocks add new building types; empty slots keep your layout intact.
